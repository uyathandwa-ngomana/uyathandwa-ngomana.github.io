## Epic A — CommunityPulse AI

### US-01 · Application development

**As a** user, **I want** the application to provide its intended functionality, **so that** I can use it for its intended purpose.

**AC:** The implemented functionality can be accessed and tested.

- T1.1 Review the project requirements
- T1.2 Contribute to application development
- T1.3 Check the implemented functionality

### US-02 · Application testing

**As a** project team member, **I want** to test the application, **so that** I can identify issues and check whether the functionality works as expected.

**AC:** Testing is performed on the available functionality, and identified issues are recorded.

- T2.1 Run tests on the available functionality
- T2.2 Identify unexpected behaviour
- T2.3 Record and report issues

## Epic B — ProKonecta Marketplace

### US-03 · Backend implementation

**As a** user, **I want** the application to process requests through its backend, **so that** its features can work with stored data.

**AC:** Backend endpoints process supported requests and return appropriate responses.

- T3.1 Implement and review backend functionality
- T3.2 Connect application features to backend endpoints
- T3.3 Test API responses

### US-04 · User authentication

**As a** registered user, **I want** to sign in securely, **so that** I can access my account.

**AC:** Authentication validates user credentials and provides access according to the account and role.

- T4.1 Review the sign-in and registration flow
- T4.2 Test authentication functionality
- T4.3 Investigate authentication errors

### US-05 · Service requests

**As a** customer, **I want** to submit a service request, **so that** I can find professionals who can assist me.

**AC:** A customer can submit a request, and the application processes it and displays appropriate feedback.

- T5.1 Implement and review service-request functionality
- T5.2 Test request submission
- T5.3 Investigate backend errors affecting requests

### US-06 · Provider directory

**As a** customer, **I want** to browse available professionals, **so that** I can find a suitable service provider.

**AC:** The directory displays available provider information and supports the intended browsing functionality.

- T6.1 Review provider directory functionality
- T6.2 Test provider listing and search
- T6.3 Identify and investigate directory issues

### US-07 · Saved professionals

**As a** customer, **I want** to save professionals, **so that** I can find them again later.

**AC:** Customers can save professionals and retrieve their saved list.

- T7.1 Review the saved professionals functionality
- T7.2 Test saving a professional
- T7.3 Investigate errors when retrieving saved professionals

### US-08 · Profile management

**As a** registered user, **I want** to update my profile, **so that** my account information remains accurate.

**AC:** Profile changes are validated, saved and displayed correctly.

- T8.1 Review the profile update functionality
- T8.2 Test profile saving
- T8.3 Investigate errors when saving profile information

### US-09 · Backend error fixing

**As a** development team member, **I want** to identify and fix backend errors, **so that** the application behaves more reliably.

**AC:** Identified errors are investigated, fixes are tested, and unresolved issues are documented.

- T9.1 Review backend error messages and logs
- T9.2 Identify the cause of errors
- T9.3 Apply and test fixes

### US-10 · Testing and debugging

**As a** development team member, **I want** to test the application's main features, **so that** I can identify problems before they affect users.

**AC:** Main user flows are tested, and working and failing features are distinguished.

- T10.1 Test the main application flows
- T10.2 Record unexpected behaviour
- T10.3 Retest features after fixes
